PULSEBRIDGE GUIDE

How to use PulseBridge

A practical guide to setup, synchronization, corrections, devices, and administration.

01Biometric devices
02PulseBridge
03ERPNext HRM

FIRST SETUP

Connect ERPNext

  1. Open Configuration.
  2. Enter the ERPNext URL, API key, and secret.
  3. Save, then choose Test connection.
  4. A green ERPNext indicator confirms authentication.

DEVICES

Add or discover clocks

  1. Open Devices.
  2. Use a range such as 192.168.0.1-254.
  3. Scan; PulseBridge confirms ZKTeco protocol on port 4370.
  4. Choose Add device, select its shift, and save.

ATTENDANCE

Run synchronization

  1. Set From and Through dates in Configuration.
  2. Use Run sync now for a backfill.
  3. Use Start continuous for unattended operation.
  4. Expand Device progress to inspect each location.

CORRECTIONS

Fix attendance safely

  1. Single-punch correction supplies a missing IN or OUT after grace time.
  2. Location switches control where synthetic punches are allowed.
  3. Off-Shift repair reprocesses existing ERPNext check-ins without changing their real times.
  4. Review unresolved rows and Activity logs afterward.

DEVICE USERS

Match employees

  1. Scan a biometric device from Device users.
  2. Filter missing, existing, eligible, or no-fingerprint users.
  3. Correct names on the clock when required.
  4. Upload selected missing users as inactive ERPNext employees for HR completion.

MAINTENANCE

Protect the installation

  1. Create encrypted backups under Administration.
  2. Backups include configuration, credentials, branding, and users.
  3. Use Activity logs to investigate failed records.
  4. Update the LXC with the documented safe updater.
